# 📚 FISI-Wissensdatenbank

Persönliche Wissensdatenbank und strukturierte Lernfeld-Dokumentation für meine Umschulung zum **Fachinformatiker für Systemintegration (FISI)**.

## 🎯 Ziel des Repositories
Dieses Repository dient als zentrales Nachschlagewerk für alle Ausbildungsinhalte, Praxisübungen und Prüfungsvorbereitungen. Alle Notizen werden im Markdown-Format gepflegt, lokal mit **Obsidian** verknüpft und über **Git** versioniert.

## 📂 Struktur & Inhalte
Die Dokumentation orientiert sich am Rahmenlehrplan sowie an fachspezifischen IT-Themen:

* **Fachspezifisches Modul 1:** Netzwerk-Grundlagen, Schichtenmodelle (OSI/TCP-IP), Adressierung, Betriebssysteme & Virtualisierung, Leistungserbringung
* **Cloud-Lösungen:** Grundlagen von Cloud-Diensten, AWS Certified Cloud Practitioner (CLF-C02), Compute (z. B. Amazon EC2)
* **Glossar:** Zentrale Fachbegriffe, Abkürzungen und Definitionen aus der IT-Systemintegration

## 🛠️ Verwendete Tools & Workflow
* **Wissensmanagement:** [Obsidian](https://obsidian.md) (Markdown-basierte Verlinkung)
* **Versionskontrolle:** Git & GitHub (Privates Backup- und Sync-Repository)
* **Automatisierung:** Obsidian Git Plugin (Automatische Synchronisation im Hintergrund)

## 📝 Dokumentations-Standards
* Klare Gliederung nach Themenblöcken und Lernfeldern
* Einheitliche Dateinamen ohne Sonderzeichen für optimale Kompatibilität
* Regelmäßige Versionierung mit sprechenden Commit-Nachrichten
